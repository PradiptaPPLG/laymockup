# 3D Isometric Mockup Studio (12-Card Light Mode & Mobile Ready)

Website statis template mockup aplikasi **3D Isometrik 1-3-4-3-1** yang **bersih dalam tema Light Mode**, terkunci presisi sesuai referensi, **responsif penuh di layar HP/smartphone**, serta mendukung **upload langsung via kamera smartphone maupun galeri file**.

---

## 🌟 Fitur & Pembaruan Terbaru

### 1. Antarmuka Light Mode Bersih & Elegan
- Seluruh antarmuka web diubah menjadi **Light Mode** modern (*clean white, soft slate surfaces, royal blue accents*).
- Default mockup kanvas langsung menampilkan **Reference Light (SMK SOPAN)** dengan 12 sampel dashboard beresolusi tinggi.
- Tetap menyediakan tombol beralih ke tema **Reference Dark (EcoVision AI)** jika diperlukan.

### 2. Responsif Penuh di HP / Smartphone
- **Kanvas Fleksibel**: Otomatis menyesuaikan ukuran layar tanpa terpotong atau menimbulkan scroll horizontal liar.
- **Drawer Panel Mobile**: Pada layar HP (< 900px), panel pengaturan berubah menjadi laci (*slide-over drawer*) yang dapat dibuka/tutup dengan tombol mengambang **Kelola 12 Foto**.
- **Topbar Ringkas**: Tombol dan teks otomatis menyusut (*compact*) tanpa saling tumpang-tindih di layar kecil.

### 3. Upload Fleksibel: Kamera Smartphone & File Galeri
- **Pilih File / Galeri**: Mendukung upload *batch* banyak file sekaligus (hingga 12 foto).
- **Buka Kamera HP**: Menggunakan `capture="environment"` untuk langsung mengaktifkan kamera smartphone Anda dan mengambil screenshot/foto dokumen secara langsung ke slot yang kosong.
- **Modal Aksi Per-Slot**: Mengetuk salah satu dari 12 slot kartu akan memunculkan menu pilihan:
  - 📷 *Ambil Foto via Kamera*
  - 📁 *Pilih dari Galeri / File*
  - 🗑️ *Hapus Foto*

### 4. Zero Cropping & Sudut Terkunci
- Tidak ada rotasi/drag sembarangan yang merusak presisi isometrik.
- Seluruh screenshot tampil 100% utuh dari bagian navbar atas hingga footer bawah tanpa terpotong.

## 📱 Panduan Penggunaan di HP & Laptop

1. **Upload Massal (Batch)**:
   - Ketuk **Pilih File / Galeri** untuk memilih hingga 12 foto sekaligus.
   - Atau ketuk **Buka Kamera HP** untuk memotret objek/layar secara langsung.
2. **Mengganti Slot Tertentu**:
   - Ketuk salah satu kartu dari 12 slot pada visual navigator 1-3-4-3-1.
   - Pilih **Ambil Foto via Kamera** atau **Pilih dari Galeri**.
3. **Ekspor Mockup**:
   - Ketuk tombol **Export PNG** di kanan atas.
   - Pilih resolusi (tersedia **Resolusi Referensi 2752×1536** atau **4K Ultra HD 3840×2160**).
   - Ketuk **Download High-Res PNG**.
